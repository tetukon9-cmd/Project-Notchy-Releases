# Notchy — Unduhan

Notchy adalah notch desktop dengan pengingat minum, agenda, fokus, jadwal sholat, hadis harian dan maskot kucing. Fitur yang tersedia berbeda menurut platform dan tahap rilis.

## Windows

[Rilis Windows 1.2.3](https://github.com/tetukon9-cmd/Project-Notchy-Releases/releases/tag/v1.2.3) menyediakan installer dan ZIP portable untuk Windows 10/11 x64 dengan .NET Framework 4.8. Keluar dari versi lama melalui ikon tray sebelum membuka versi baru. Profil lokal tidak perlu dihapus.

## Linux dan macOS

Versi Linux dan macOS sedang dikembangkan. Paket akan diumumkan setelah build dan pemeriksaannya selesai. Tidak ada klaim kesetaraan seluruh fitur Windows pada tahap pratinjau.

## Paket dan lisensi

Repository ini hanya memuat halaman unduhan, pemberitahuan lisensi, dan paket hasil build pada Releases. Source aplikasi, semua branch pengembangan dan riwayatnya dikelola secara privat.

Arsip otomatis GitHub bernama **Source code** hanya berisi halaman unduhan ini dan pemberitahuan lisensi, bukan source aplikasi Notchy. Paket aplikasi tidak menyertakan project, source, skrip build atau simbol debug. Binary tetap dapat dianalisis; distribusi tertutup bukan jaminan anti reverse engineering.

Lihat `checksums.json` pada setiap rilis untuk SHA256 paket. Pemberitahuan Gili, Sela, audio, dan komponen pihak ketiga tetap disertakan dalam aplikasi/paket. Hak dan lisensi komponen tersebut tetap berlaku.
